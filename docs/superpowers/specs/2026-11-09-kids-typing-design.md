# 小键盘大冒险 · 儿童打字软件设计文档

- 日期：2026-11-09
- 状态：待审阅
- 视觉稿：https://claude.ai/artifact/7YWKQKkXZvTSFnaS8UStKe（6 个页面的可点击原型）

## 1. 目标

给 4–6 年级小学生用的打字练习软件，Mac 和 Windows 都能用。核心思路是**边读课外书边练打字**：孩子打的是统编语文「快乐读书吧」推荐的书，在练指法和拼音的同时读完一本书。

成功标准：

1. 孩子不需要大人帮忙，就能自己完成「选书 → 打一段 → 看成绩 → 领奖励」整个流程。
2. 所有按钮和触控目标至少 56px 高，主要按钮至少 64px，正文字号至少 17px。
3. 在 Mac（Safari / Chrome）和 Windows（Edge / Chrome）上表现一致，不依赖系统自带的中文输入法。
4. 断网也能用：第一次打开之后，所有内容都缓存在本地。

## 2. 用户与场景

- **孩子（主要用户）**：9–12 岁，会拼音，指法大多不规范。每次练 10–20 分钟，在家里电脑上用。
- **家长 / 老师（次要用户）**：看练习情况、限制每天的时长、导入自己的文章。
- 一台电脑上可能有多个孩子用，所以要支持多个本地档案。

**做：**

| 模块 | 内容 |

## 4. 平台与技术选型

- **形态**：网页应用（PWA）。浏览器打开就能用，可以「安装到桌面」，并能离线运行。
- **技术栈**：Vite + React + TypeScript；Vitest 做单元测试；vite-plugin-pwa 做离线缓存。
- **以后打包桌面版**：第二版用 Tauri 打包成 .exe / .dmg，代码不需要改。
- **存储**：只存在本机浏览器（localStorage），不建服务器。家长中心可以导出和导入 JSON 备份，用来换电脑或防止数据丢失。
- **字体**：
  - 标题用 ZCOOL KuaiLe（站酷快乐体），数字和字母用 Fredoka。两个字体都放在本地，按需裁剪字集，保证离线可用。
  - 正文用系统字体：Mac 上是 PingFang SC，Windows 上是 Microsoft YaHei，再兜底到 Noto Sans SC。这样不用打包几 MB 的中文字体。
- **声音**：按键音和答对、答错音效用 Web Audio 实时合成，不需要音频文件。「听一听」用浏览器自带的中文语音（speechSynthesis）；如果系统里没有中文语音，就隐藏这个按钮。

## 5. 核心：拼音直打引擎

引擎写成纯 TypeScript 模块（`src/engine/`），不依赖界面代码，方便单独测试。

### 5.1 数据

一段课文是一个 token 数组：

```ts
type Token =
  | { kind: 'hanzi'; char: string; key: string; tone: string } // key: 'zhong'，tone: 'zhōng'
  | { kind: 'skip'; char: string };                             // 标点、空格、数字等
```

- `key` 是孩子要按的字母序列：只有 a–z，ü 写成 `v`（女 → `nv`）。j/q/x/y 后面的 ü 按课本写法打 `u`（去 → `qu`）。
- 多音字在制作内容时就标好（第 7 节），运行时不做判断。

### 5.2 规则

1. 光标指向当前汉字的第 `pos` 个字母。按对了就前进；这个字的字母打完，就自动跳到下一个汉字，中间所有 `skip` 字符自动跳过。
2. 按错时不前进：这次按键记为错，屏幕键盘上把按错的键标成橙色，键宝换成担心的表情，并提示正确的手指。
3. 大小写都接受。字母以外的键（数字、符号、功能键）一律忽略，不算错。
4. 按退格键没有作用（错字本来就不会写进去，所以不需要删）。
5. 如果检测到中文输入法正在拼写（`keydown` 事件里 `isComposing` 为真，或 `key === 'Process'`），本次按键不计入，并显示提示条：「按一下 Shift 切换成英文」。
6. 窗口失去焦点，或者 10 秒没有按键，就自动暂停计时；按下一个键时继续。

### 5.3 统计

- **速度（字/分）**：完成的汉字数 ÷ 有效时间。两次按键之间超过 5 秒，只按 5 秒算，这样孩子停下来读书不会拉低速度。
- **正确率**：按对的次数 ÷ 总按键次数，四舍五入到整数百分比。
- **星星**：正确率 ≥ 95% 得 3 星，≥ 85% 得 2 星，其余得 1 星。
- **易错键**：按「应该按的键」统计出错次数，结算页显示出错最多的 3 个键。

### 5.4 指法映射

使用标准指法。左手：小指 Q A Z，无名指 W S X，中指 E D C，食指 R T F G V B。右手：食指 Y U H J N M，中指 I K ,，无名指 O L .，小指 P ; /。空格用大拇指。屏幕键盘按手指分 4 种颜色，左右手对称用同一套颜色；下一个要按的键用黄色高亮并上浮。

## 6. 奖励体系

| 奖励 | 条件 | 说明 |
|---|---|---|
| 星星 | 每完成一段（或一关、一局游戏）得 1–3 颗 | 读书小考考答对再加 1 颗 |
| 徽章 | 完成一个章节，或达成里程碑（初次上手、连对 50 个、指法毕业等） | 第一版共 30 枚 |
| 小皮肤 | **累计打字量每满 500 字**解锁下一个 | 按固定顺序解锁：红围巾 → 薄荷键宝 → 圆圆眼镜 → 小草帽 → 天空键宝 → 蝴蝶结 → 草莓键宝 |
| 大皮肤 · 读书 | **读完一整本书**（所有段落都完成） | 每本书对应一套。第一版：中国古代神话 → 后羿小射手，中国民间故事 → 神笔小画家，西游记 → 美猴王，三国演义 → 卧龙军师，水浒传 → 梁山好汉，古诗词小站 → 小诗仙。「即将上线」的书在书架上显示对应皮肤名，但不计入衣橱 |
| 大皮肤 · 速度 | **速度第一次达到新等级** | 起步等级是蜗牛（低于 20 字/分，没有皮肤）；之后依次是小兔 20 / 骏马 30 / 猎豹 40 / 火箭 50 字/分 |

- **打字量**：读书岛、拼音快打、龙宫泡泡里完成的汉字数，三者合计。指法训练营只发星星和徽章，不计入打字量。
- **速度等级认定**：只有满足以下全部条件的一段，才算达到该等级。这样可以防止孩子打几个字冲一下速度。
  - 这一段有至少 30 个汉字（古诗太短，不参与速度认定）；
  - 正确率 ≥ 90%；
  - 速度 ≥ 等级门槛。
- **解锁时机**：解锁动作发生在结算页，带庆祝动画，并有「马上穿上」按钮。奖励一旦获得就永久保留。
- **可调参数**：500 字的步长和各速度门槛都写在配置文件 `src/rewards/config.ts` 里，以后要调整只改这一个文件。

## 7. 内容

### 7.1 版权原则

只使用以下几类内容：

1. 公版原文：四大名著、古诗词、作者已去世超过 50 年的中文作品；
2. 我们自己改写的故事：神话、民间故事等；
3. 拿到授权的内容。

**有版权的中文译本不能直接录入。** 比如《童年》《爱的教育》等外国名著的现行中文译本，以及《细菌世界历险记》这类作者去世不到 50 年的作品，第一版先显示「即将上线」，以后自己改写或购买授权。

### 7.2 第一版上线书目

| 年级 | 书 | 来源 | 段数（每段 40–80 字） |
|---|---|---|---|
| 四上 | 中国古代神话 | 自写改编（盘古、女娲、后羿、精卫、夸父等） | 20 |
| 五上 | 中国民间故事 | 自写改编（牛郎织女、神笔马良、田螺姑娘等） | 20 |
| 五下 | 西游记 | 原著第一回至第七回选段 | 24 |
| 五下 | 三国演义 | 原著选段（桃园结义、草船借箭等） | 24 |
| 五下 | 水浒传 | 原著选段（景阳冈等） | 24 |
| 通用 | 古诗词小站 | 公版古诗 30 首 | 每首 1 段 |

其余书（希腊神话、十万个为什么、红楼梦、童年、鲁滨逊等）先放在书架上，标「即将上线」。

### 7.3 内容格式与制作流程

- 每本书一个 JSON 文件，放在 `src/content/books/<id>.json`：

  ```json
  {
    "id": "xiyouji",
    "title": "西游记",
    "author": "吴承恩 · 明",
    "grade": 5,
    "term": "下册",
    "theme": "古典名著",
    "skinId": "monkey",
    "skinName": "美猴王",
    "cover": "#FF7A45",
    "mark": "西",
    "kind": "prose",
    "segments": [
      { "id": "c1-1", "title": "第一回 · 花果山", "tokens": ["…"], "quiz": { "q": "…", "options": ["…"], "answer": 0 } }
    ]
  }
  ```

- 制作流程：
  1. 准备 `.txt` 原文；
  2. 运行脚本 `scripts/annotate.ts`，用 pinyin-pro 自动标注拼音，生成 JSON；
  3. 人工核对多音字；
  4. 运行脚本 `scripts/validate.ts` 校验。
- 校验内容：
  - 每个汉字都有 `key`，且 `key` 只包含 a–z；
  - 每段字数在范围内：普通段落 40–80 字，古诗 16–120 字；
  - `skinId` 存在；
  - 小考考的答案下标合法。

## 8. 存储与数据模型

```ts
type Profile = {
  id: string; nickname: string; grade: 4 | 5 | 6;
  stars: number; totalChars: number; bestSpeedLevel: 0 | 1 | 2 | 3 | 4;
  badges: string[]; skinsOwned: string[]; skinWorn: string;
  bookProgress: Record<string, { done: string[]; lastSegment: string; updatedAt: number }>; // done 存段落 id；updatedAt 用于首页「继续读」
  keyErrors: Record<string, number>;
  daily: Record<string, { minutes: number; chars: number }>;             // 键为 'YYYY-MM-DD'
  settings: { dailyLimitMin: number; sound: boolean; showPinyin: boolean };
};
```

- 所有档案存在同一个 localStorage 键 `kbd-adventure/v1` 下，结构带版本号，以后数据格式变了可以迁移。
- 每完成一段就保存一次。
- 如果 localStorage 不可用（比如无痕模式），数据只放在内存里，并在顶部提示「这次的进度不会保存」。

## 9. 页面清单

页面布局和视觉风格以设计稿为准。

1. **首次启动**：选一个头像、输入昵称、选年级，三步完成，大按钮。
2. **首页**、**读书岛**、**打字练习页**、**龙宫泡泡**、**结算页**、**皮肤衣橱**：同设计稿。
3. **指法训练营**：沿用打字练习页的键盘和手指组件，练习内容换成字母串，每关约 60 次按键；正确率 ≥ 90% 才能开下一关。
4. **拼音快打**：沿用同一个引擎，练习内容是单个音节和词语。
5. **家长中心**：
   - 入口：做一道两位数加法题才能进入。
   - 功能：近 7 天的时长和速度、易错键、每日时长上限（默认 20 分钟，到时间键宝提醒休息，不强制退出）、粘贴文章导入（自动标注拼音，生成「我的文章」书架）、导出和导入备份。

## 10. 视觉规范

- **风格**：「玩具积木贴纸」。3px 深蓝描边，下方 6–8px 实色投影，圆角 16–32px，不用渐变。
- **颜色**：
  - 背景 天蓝 `#E3F2FF`，文字和描边 深蓝 `#1F2A44`；
  - 主色 阳光黄 `#FFC93C`，辅色 珊瑚橙 `#FF7A45`；
  - 成功 薄荷绿 `#34C38F`，奖励 紫 `#8B6CFF`；
  - 手指分区底色：小指 `#EDE6FF`、无名指 `#DDF5EA`、中指 `#DCEBFF`、食指 `#FFE6D3`。
- **对比度**：所有文字对比度 ≥ 4.5:1，大字 ≥ 3:1。表示「对 / 错」时，除了颜色还要有图标或动效，照顾色弱的孩子。
- **吉祥物「键宝」**：一个键帽形状的小家伙。用 SVG 分层绘制，方便换装：身体颜色 + 配饰图层。

## 11. 错误处理

| 情况 | 处理 |
|---|---|
| 开着中文输入法 | 按键不计入，显示切换提示（5.2 第 5 条） |
| 没有中文语音 | 隐藏「听一听」 |
| 存储不可用或已满 | 只在内存里保存，并显示提示；导出备份功能仍然可用 |
| 导入的备份格式错误 | 拒绝导入并说明原因，不覆盖现有数据 |
| 导入的文章含生僻字，拼音库标不出来 | 这个字改为 `skip`，并提示家长 |
| 窗口失焦或长时间不按键 | 自动暂停 |

## 12. 测试

- **单元测试（Vitest）**：
  - 引擎：前进、错键、跳过标点、ü→v、输入法检测、暂停与速度计算；
  - 奖励：500 字步长、读完一本书、速度等级认定的三个条件；
  - 存储：版本迁移、损坏数据的处理。
- **内容校验**：`npm run validate` 检查所有书的 JSON，构建前自动运行。
- **组件测试（Testing Library）**：键盘高亮、手指提示、结算页奖励弹出。
- **手动验收**：在 Mac Safari / Chrome 和 Windows Edge / Chrome 上各跑一遍完整流程：首次启动 → 打完一段 → 领皮肤 → 换装 → 家长导出备份。
